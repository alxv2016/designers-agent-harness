# ux-designer — Consistency with the product's model

What scores of 0, 2 and 4 look like on this dimension, for the `ux-designer` judge. Consistency with the product's model: the same concept, word and gesture meaning the same thing everywhere. Its weight is in `.agents/evals/weights.json`; how it is scored is the judge's rubric, Quality (.agents/HARNESS.md §12).

**Measured proxies — none.** The judge scores this dimension on its reading alone.

**How to use it.** Find the level the work sits nearest, quote the evidence — a file and line, a screenshot, a measured value — and give 1 or 3 when it sits between two. The person's own examples, under From the person, outrank the ones written here.

## 4 — what good looks like

- One conceptual model across the product — each control means the same on every screen; objects named once; a new flow uses the patterns the person already knows (HCI §2 H4).

## 2 — acceptable, with a clear gap

- Mostly consistent, with one screen where a key or a word means something else.

## 0 — what fails it

- Each flow its own rules: the same key backs out on one screen and confirms on another.
