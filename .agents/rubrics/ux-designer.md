# Rubric — ux-designer

How the [ux-designer](../agents/ux-designer.md) scores an experience in review mode. The verdict, the evidence rules,
the items X1–X14 and the report's shape travel with the skill, in
[`ux-designer/references/rubric.md`](../skills/ux-designer/references/rubric.md) (UX_REVIEW_RUBRIC), so the agent and
the skill work in any repo. This file holds what this project adds: the items learned from what people found in testing
or on the target ([verify-change](../skills/verify-change/SKILL.md#recording-what-was-learned) → Recording what was
learned, route `rubric`). Each item is a flow, structure or behaviour the person said no to or found wrong — from
`verify.py decline` or `verify.py finding --route rubric --judge ux-designer` — and the ux-designer reads them before
its next draft as well as in review. A review scores the skill's items and every item here. A new learned item goes
here, not in the skill or the agent.
